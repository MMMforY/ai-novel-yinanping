# 迭页本地 MVP

实现日期：2026-10-07。产品定义沿用本仓库原有文档，视觉参考 [Figma 归档](./design/figma/README.md)。

## 启动与目录

Node.js 22.22.2+，执行 `npm install`、`npm run dev`，打开 http://localhost:5173/。停止时在启动终端按 Ctrl+C。配置 .env 或修改服务端代码后需要重新启动；前端代码由 Vite 热更新。

| 目录 | 职责 |
| --- | --- |
| `src/App.tsx`、`src/styles.css` | 首页、创建、导入、阅读、选区浮层、改写弹层和世界线结果 |
| `src/domain.ts` | 故事、版本、选区锚点、改写分叉及续写规则 |
| `src/selection.ts` | 根据 DOM Range 端点及段落源偏移映射选区，不依赖文本第一次匹配 |
| `src/storage.ts` | IndexedDB 读写；阅读位置独立事务更新，避免覆盖新增正文 |
| `server/app.ts` | 本地 HTTP API；生产构建静态文件服务 |
| `server/model.ts` | 演示 / 真实模型适配、输入校验、上下文窗口和错误处理 |
| `shared/` | 前后端接口约定、输入限制与原创演示片段 |
| `tests/` | 版本与选区测试、模型协议测试、桌面 / 手机尺寸浏览器测试 |

网页与模型代理分别在 localhost:5173 和 127.0.0.1:8787 运行；Vite 代理 /api 请求。生产构建 `npm run build` 后运行 `npm start`，可在 http://127.0.0.1:8787/ 使用。

## 模型配置

复制根目录 .env.example 为 .env，填写服务地址、模型和密钥。前缀示例：`https://your-provider.example/v1`，服务端追加 `/chat/completions`。兼容接口必须支持非流式请求，并返回 `choices[0].message.content`。

提示词要求输出 `{"title":"世界线标题","text":"中文小说正文"}`。正文直接渲染为文字段落，不执行模型输出的 HTML。具体供应商的兼容性需要用真实凭据确认。

- `LLM_BASE_URL`：模型服务接口前缀。
- `LLM_MODEL`：模型名称。
- `LLM_API_KEY`：服务端密钥。
- `LLM_ALLOW_NO_KEY=true`：明确使用无需密钥的本地服务。
- `LLM_TOKEN_PARAMETER`：默认 max_tokens，可改为 max_completion_tokens。
- `LLM_MAX_OUTPUT_TOKENS`：默认 1800，允许 300—6000。
- `LLM_CONTEXT_CHARS`：默认 18000，允许 6000—80000 字符预算。
- `LLM_TIMEOUT_MS`：默认 90000，允许 1000—180000 毫秒。
- `API_PORT`：默认 8787；网页代理随配置调整。
- `WEB_PORT`：可选，默认 5173。改变端口会使用不同的浏览器故事库。

没有地址、模型和密钥配置时，使用预设演示片段；有部分配置时会提示缺失项。已配置服务请求失败、超时或返回格式不正确时，保留用户输入与已有正文，支持重试，不生成假结果。

发送给真实模型的内容包括意图、模式、背景、当前版本 ID、选区及其完整正文偏移和必要前后文。长正文使用有限窗口：优先保留选区、靠近干预点的前文和部分后文约束。此预算按字符计算，供应商仍可能因其 token 限制拒绝请求。

## 版本与保存

导入原稿完整保留在 originalText，包括 BOM、换行和首尾空白。阅读正文单独统一 CRLF / CR 换行、去除 BOM 和首尾空白；保存后的原版不被改写或续写覆盖。

改写新版本由“父版本干预点之前的正文 + 模型生成的替代后续”组成，不自动拼回可能冲突的旧后文。世界线保存父版本、意图、模式、选区偏移、来源正文快照、生成来源和阅读进度。

续写原版会先建立续读世界线；续写现有世界线只追加该版本正文。版本切换与刷新可以恢复正文和阅读位置。桌面结果页显示改写前后对照，手机显示当前结果并提供切换。

故事保存在 IndexedDB 数据库 dieye-local 的 stories 表。模型密钥不在其中。开发与生产地址、不同浏览器或不同端口的存储互相隔离；没有云同步或自动备份。

生成请求使用取消信号与请求序号。取消、离开页面或切换版本后，旧响应不会覆盖当前状态。生成期间避免重复提交，成功并保存后才建立新版本。

## 尚未验证与当前限制

- 未提供真实模型凭据，因此未验证外部供应商可用性、真实输出质量或“改完后愿意继续读”的用户假设。
- 未用真实手机验证系统长按手柄、软键盘遮挡及操作系统选择菜单。已实现原生选区监听，并提供段落改写入口。
- 演示输出是固定模板，只能验证操作流程，不代表模型理解任意意图。
- 首版处理片段 / 章节，不具备整部小说的长期人物记忆；最小改变与重新汇入主线是提示词目标。
- 导入 30000 字、UTF-8 TXT 120KB、选区 2000 字、意图 600 字、背景 1200 字；每次返回正文最多 12000 字，单版本正文最多 120000 字。
- 没有 DOCX、账号、同步、社区、付费、检索、自动抓取或复杂分支图。
- 数据量超过浏览器容量时会提示保存失败；已有存储和输入保留。本版尚无故事导出 / 备份功能。
